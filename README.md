# KWAN vs FARCHI — Ultra Street Rooftop Fighter 2000

משחק לחימה דו-ממדי בסגנון משחקי פלאש של פעם, שרץ ישר בדפדפן.
הפרצופים של הלוחמים הם תמונות אמיתיות שנחתכו מהרקע והולבשו על גוף מצויר — סגנון סאות׳ פארק.

**לשחק עכשיו:** פותחים את `index.html` בדפדפן. זהו. אין התקנה, אין build, אין תלויות.

## מכניקה

- **מכות**: אגרוף ובעיטה בעמידה, בכפיפה ובאוויר — שש התקפות שונות בסך הכל.
- **גבהים**: בעיטה בהתכופפות היא מכה **נמוכה** (חייבים לחסום בכפיפה), ובעיטה מהאוויר היא מכה **גבוהה** (חייבים לחסום בעמידה). חסימה לא נכונה = חוטפים.
- **חסימה** מורידה את הנזק ל-18% ומונעת נפילה.
- **מד SPECIAL** מתמלא כשמכים וכשחוטפים. כשהוא מלא — המהלך המיוחד זמין (24 נזק + הפלה).
- **קומבו**: מכות רצופות לפני שהיריב מתאושש נספרות ומוצגות על המסך.
- **מבנה**: הכי טוב מ-3 סיבובים, 60 שניות לסיבוב. נגמר הזמן — מנצח מי שנשאר עם יותר HP.
- מצב שחקן יחיד נגד מחשב, או שני שחקנים על אותה מקלדת.

## מבנה הפרויקט

```
index.html                 המשחק כולו — קנבס, מנוע, ציור, סאונד, והתמונות מוטמעות כ-data URI
assets/head_farchi.png     הראש של פרחי, רקע שקוף + קו מתאר שחור
assets/head_kwan.png       הראש של קוואן
scripts/build_faces.py     מטמיע מחדש את התמונות מ-assets/ לתוך index.html
scripts/serve.py           שרת סטטי מקומי לפיתוח (לא חובה)
```

`index.html` הוא קובץ אחד עצמאי — אפשר לשלוח אותו בוואטסאפ והוא יעבוד.

### להחליף פרצוף

1. שמים תמונת ראש עם רקע שקוף בשם `assets/head_farchi.png` או `assets/head_kwan.png`.
2. מריצים:

```bash
python3 scripts/build_faces.py
```

הסקריפט ממיר ל-base64 ומחליף את הבלוק בין `/*FACES_START*/` ל-`/*FACES_END*/` בתוך `index.html`.
אם התמונות לא נטענות, המשחק נופל אוטומטית לפרצופים המצוירים שבנויים בקוד.

### שרת מקומי (אופציונלי)

```bash
python3 scripts/serve.py 8765
```

הכל Canvas 2D ו-Vanilla JS, בלי שום ספרייה. הרקע, הקהל, העננים, קווי הסריקה, הצלילים
(WebAudio) ולולאת הבס — הכל מיוצר בזמן ריצה. הדמויות מצוירות כשלד: הגפיים מחושבות
בזוויות לפי מצב הדמות (עמידה, הליכה, קפיצה, אגרוף, בעיטה, מכה, נפילה), והראש המצולם
מולבש מעל. מנוע המשחק רץ בצעד קבוע של 60 פריימים לשנייה.
